# Shadowblade Forge

A responsive e-commerce website for **Shadowblade Forge**, a fantasy-inspired artisan business creating handcrafted leather goods, artisan dice, and accessories for modern-day adventurers.

🌐 **Live Site:** https://shadowbladeforge.com

## About the Project

Shadowblade Forge began as a real-world business website and has also become a portfolio project focused on building a production-ready application with modern web development practices.

The site was designed and developed from the ground up with an emphasis on reusable components, responsive design, accessibility, server-side functionality, and maintainable TypeScript architecture.

## Features

- Responsive desktop and mobile layouts
- Reusable React components
- Typed component props with TypeScript
- Next.js App Router architecture
- Dedicated shop and collection pages
- Forge Journal blog architecture
- Accessible contact form
- Server-side form validation with Zod
- Email delivery through Resend
- Environment variable management
- Dynamic page metadata
- Custom responsive navigation
- Production deployment with Vercel
- Custom domain configuration

## Tech Stack

- **Next.js**
